SESS Idle Agent

Connect this machine to your organisation's SESS server.

What this records: whether your machine received keyboard or mouse input, summarised as idle/active minutes and sent every 15 minutes.

What it does not record: no screenshots, no application or window names, no websites, no keystrokes, and no productivity score.

The tray icon stays visible whenever this is running, and you can pause tracking at any time from its menu.

Treat this like a password — it identifies this machine to the server.
